# Clearlyy animation skills

Claude Code skills for the animations made in this project. Each folder is one skill (`SKILL.md` plus any scripts). They live in a project's `.claude/skills/` folder.

| Skill | What it covers |
| --- | --- |
| `job-haters` | The 13learns "Job haters" series: 12s faceless 3D metaphor loops (HyperFrames + Three.js). It covers ideas, scripts, scaffolding, scene.js, SFX, review and render, and holds the house rules. |
| `jh-*` (39) | One per finished Job haters video: its script, where its on-screen text lives, timing constants, scene builders, sound notes and re-render steps. |
| `oneif-ep01-never-sleep`, `oneif-ep02-remember-everything` | One If long-form episodes (Bold Toon SVG films, 1920×1080): story, cast and voices, word-cued cuts, and the audio and caption pipeline. |
| `oneif-short-s01` … `s04` | One If vertical Shorts, built on the `runShort` / `vscenes` framework. |
| `pixar-ai-midterms` | A 3D-feature-style storyboard animatic: image-and-voice pipeline, score and mix. |

The skills refer to project files (`videos/`, `whatif/`, `SCRIPTS-*.md`, `sfx-library/`, …) that are **not** in this repo, so they're most useful inside the original project.
